## Reuse

Select the existing `ui/Dialog`, `ui/AlertDialog`, `ui/Menu`, `ui/Tooltip` and `ui/IconButton` wrappers, with `keys/registry.ts`'s `registerKeys` for shortcuts. [Ark Tabs](https://ark-ui.com/docs/components/tabs) offers controlled selection, manual activation and composed triggers; probe the installed version with rename, attention-mark actions, sibling close controls and overflow before adoption. [Ark Dialog](https://ark-ui.com/docs/components/dialog) supplies modal focus and dismissal. [Ark package metadata](https://registry.npmjs.org/@ark-ui%2fsolid) records MIT 5.39.3 released 2026-10-05. The installed version, rather than the documentation's latest API, decides compatibility.

[Kobalte](https://github.com/kobaltedev/kobalte) is a maintained Solid alternative; its [metadata](https://registry.npmjs.org/@kobalte%2fcore) records MIT 0.13.14 released 2026-09-07. It is deferred under `docs/adr/0009-app-component-layer.md`, heading “Reuse considered”: Ark is the selected layer, with Kobalte a fallback for a reproducible budget miss. No capability or performance defect is claimed for Kobalte. No custom component engine is permitted. If the existing shared exports cannot express Tabs or another required control, file the missing shared primitive, block implementation and keep the lane's ownership boundary.

**U496 Drawer Escape follows layer scope.** Given an open item Drawer, when Escape is pressed outside an editable field or Terminal, then only that Drawer closes and focus returns to its connected origin if focus stayed in the Drawer; focus deliberately moved elsewhere is preserved (`u496_drawer_escape_and_return`, planned under `drawer/`). Given an input, textarea, contenteditable or Terminal owning Escape, it receives its existing behavior and the Drawer remains open (`u496_editor_and_terminal_keep_escape`). Given Models or a Project menu above an open Drawer, one Escape dismisses only that top surface, leaves Drawer content unchanged and sends no Terminal input; repeat after reversing mount order (`u496_top_layer_escape_is_order_independent`, planned lane browser observer).
