# UI: the Rail's task field (U2227)

Module: `apps/desktop/src/rail/` (the webview): `SpawnPromptField.tsx`, its rules in `styles.css` and the `copy.ts` entries it uses. Ids: U2227. Found by a break-ui run on `⇧⌘N` (#2227): the field is a 287 px single-line input with no hint, a 2 px blue focus outline, and shows only the last 30 characters of a 200-character task; Esc drops the text silently. Narrows U33 (its field, its Esc and its Enter); changes no Daemon method, App seam command or Token, and U33's chord, trimming, parent rule, failure line and focus-to-pane rules stand.

**U2227 the task field shows the whole task, says what to type and keeps the draft.** Given an open Project and the Rail at its default width on `tree-40` (U26), when the user presses `⇧⌘N`, then:
- **A task field, flat.** The field is a multi-line text field (a `textarea`) with `aria-label` `Task`. Asserted in `u2227_the_field_is_a_textarea`.
- **Enter and Shift+Enter.** Enter starts the Agent as U33 says; `Shift+Enter` inserts a newline and starts nothing; Enter during an IME composition starts nothing. Interior newlines reach `prompt` unchanged and the ends are trimmed as U33 trims. Asserted in `u2227_enter_starts_the_agent`, `u2227_shift_enter_adds_a_line` and `u2227_enter_during_composition_starts_nothing`.
- **Esc keeps the draft.** Esc closes the field and calls nothing, as U33 says, but the typed text is kept for the Project: `⇧⌘N` opens the field again with that text, focused and the caret at its end. The draft ends only when the user empties the field or an `agent.spawn` from it succeeds; a failed call keeps it, as U33 says. Asserted in `u2227_escape_closes_the_field_and_the_next_open_restores_the_text` and `u2227_the_draft_ends_when_emptied_or_after_a_successful_spawn`.
- **One chord.** Starting an Agent with a task is `⇧⌘N`, the task, Enter: no pick and no further step, fewer than Solo's `⌘T`, pick, task. Asserted in `u2227_a_task_starts_with_the_chord_the_text_and_enter`.

Tests (`u2227_`, Vitest against the fake App, in `apps/desktop/src/rail/`). The `input` selectors in `u33_spawn_with_prompt.test.tsx` and `u133_click_targets.test.tsx` change in the same PR.
