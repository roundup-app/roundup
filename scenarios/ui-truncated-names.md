# Truncated names can be read in full

Acceptance for #2228, found by break-ui on `tree-40` with a Workstream named `payments workstream` plus a very long tail. Webview only: no App command, no Daemon method, nothing under `contracts/` and no Token changes. Owns `apps/desktop/src/rail/` (the row's name) and `apps/desktop/src/header/` (the window bar's title). Narrows U65 (`scenarios/ui-rail.md`) and U449's overflow clause (`scenarios/ui-window-bar.md`); U29's ellipsis, U46's unmoved rows and U450's title text hold.

The journey stage is Understand (`.agents/data/journey.md`): the user can tell which Workstream a row or the window names, whatever its length.

**U2228a a truncated Rail name is readable in full.** Given `tree-40` with a Workstream whose name is 80 characters, at a Rail width of 252 px, when its row is hovered or keyboard-focused, then the full unchanged name shows in a tooltip drawn in the platform's tooltip style, for a Workstream row as for a Door, Agent or Project row (U65 already says so; the Workstream row today carries none). The row's accessible name holds the full name, not the cut text. A name that fits has no tooltip of its own and no extra accessible text; the Add Agent button keeps its own tooltip, and a hover on it shows that one only. The rename field still holds the full name (U61). Asserted in `u2228a_a_truncated_workstream_name_has_its_full_text`, `u2228a_a_name_that_fits_has_no_tooltip` and `u2228a_the_add_agent_tooltip_stays` (jsdom: attribute and accessible name). Policy: when U521 (`scenarios/ui-rail-lane.md`) lands, its shared Tooltip carries this same text and these tests move to it unchanged.

**U2228b the window title keeps the name's start and end.** Given the window bar's title (U449, U450) for `<Project> — <Workstream>` too long for its box, then the visible text is cut in the middle with a single `…`: it begins with the start of the Project name and ends with the last characters of the Workstream's name, never ending in `…`. A title that fits is shown whole with no `…`. The visible text fits on one line in the box, whose midpoint stays at half the window width (U449), at 1280×800 and 1600×800 with a 300-character Workstream name and with a long Project name. The accessible name and `title` stay the full, untruncated text, and so does the native window title (U450). Widening or narrowing the window re-cuts the text without a reload, and a rename updates the cut after the successful response (U450). Asserted in `u2228b_a_long_title_keeps_start_and_end` (the visible text starts with the Project's first characters and ends with the Workstream's last ones, contains one `…`), `u2228b_a_short_title_is_whole`, `u2228b_the_full_title_stays_in_name_and_window` and `u2228b_resize_recuts_the_title` (headless Chromium, the box measured with the real font, not jsdom). Replaces only U449's "stays on one line with ellipsis" wording for the title; its centring, overlap and accessible-name clauses hold.

Reuse (rule 9, policy): the implementing PR researches existing middle-truncation helpers and the shared `ui/Tooltip` before adding code, and carries the `Reuse:` section with at least two maintained candidates and the evidence for the choice.

Checks it moves (rule 8): D2, D5 and D6 hold on the densest seed, light and dark, with no Check passing on `main` regressing (the design critic judges them, AGENTS.md rule 10; `u2228b_a_long_title_keeps_start_and_end` proves the cut).
