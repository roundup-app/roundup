# Replace custom machinery with its library

Work order: #3742. Scope: the cases below in `apps/desktop/src`, the named crates, and one guard in `tools/` wired into `justfile`. This specification delivers acceptance only. Implementation is split by module directory under AGENTS.md rule 3; progress, capability findings and remaining work belong on the canonical Issue, never in this file.

## Common acceptance

Policy for every heading: check the named library/platform against the actual caller requirements and installed version, including repository patches, before replacement. Delete the superseded implementation and dead callers; relocating it, wrapping it, or introducing equivalent custom machinery does not satisfy the case. If the feature cannot preserve the required behavior, retain that case and record on #3742 its file/symbol, required behavior, library version, primary source and a reproducible capability probe showing the missing capability. A concrete limitation satisfies that case's alternative; preference or implementation effort does not. No replacement is claimed until all the case's sites are accounted for.

Policy: retain behavior and the existing tests for every changed surface unchanged. Run the tests reached by each changed file, plus `just lint-web` and `just lint-rust`; CI judges the full push. New behavioral tests are needed only for an otherwise unproved clause, follow rule 10 and use the heading's lowercase id. The source-deletion requirements below are policy checked in the diff, not text-matching tests of implementation. No RPC, persisted identity, Message law, Token value or domain term changes are ordered.

Policy: each implementation PR supplies rule 9's `Reuse:` comparison, with at least two maintained candidates, primary links, release/maintenance evidence, installed dependency/platform inspection and a specific reason for each rejection. The libraries and platform features below are the first candidates, not permission to skip the capability check. Dependencies may change in the owning module's PR. Shared callers change atomically; if module isolation cannot preserve the contract, record the needed seam repair on #3742 and file a scoped prerequisite rather than widening ownership silently.

Library starting points (policy): inspect the installed Ark 5.39.3 and OverlayScrollbars 2.17.0 APIs and patches first. [Ark's Solid release](https://github.com/chakra-ui/ark/releases/tag/%40ark-ui/solid%405.39.3) was published 2026-10-05; [OverlayScrollbars 2.17.0](https://github.com/KingSora/OverlayScrollbars/releases/tag/v2.17.0) on 2026-10-20. Primary capability references: [Ark Splitter](https://ark-ui.com/docs/components/splitter), [Ark Dialog](https://ark-ui.com/docs/components/dialog), [OverlayScrollbars options](https://kingsora.github.io/OverlayScrollbars/), [wait-timeout](https://docs.rs/wait-timeout/latest/wait_timeout/), [time](https://docs.rs/time/latest/time/struct.OffsetDateTime.html), [shlex](https://docs.rs/shlex/latest/shlex/fn.try_quote.html) and [url](https://docs.rs/url/latest/url/struct.Url.html). These establish candidates, not proof that each existing caller is supported.

## UI observers and gates

Policy: preserve the Enter, Understand, Intervene and Review steps of `.agents/data/journey.md` on each changed path. Focus changes must not consume, send or retarget unfinished work (P11); notification changes must not create routine attention (P3); launch changes preserve the user's vendor setup (P4) and authorized starts/prompts (P9). The applicable gates ask whether that changed path violates those rules. Use the existing App seam and existing continuity/launch observers for those answers, not a new mock-only owner.

Policy: every UI implementation has a design-critic pass at 1512×950, dark mode, on `tree-40`, `agents-10` and `conflict` as relevant, plus the interaction's existing seed. Exercise the affected control, keyboard focus, dense content and visible failure text. Check D2, D5 and D6 (`docs/design-system.md`, heading `The checks`), name all other Checks the change moves and regress none passing on main. `just capture <ids>` leaves PNGs/videos under `artifacts/ux/<id>/`; never commit them. The critic judges layout, clipping, colour and motion; behavioral tests assert actions, focus, roles and calls. Only Tokens style the changed UI. Browser observers use dedicated headless sessions and fresh profiles. No new Mac-only observation is required for a library substitution.
