# The Door is the user's Terminal

Source: the owner's report and choices in #1497 (2026-10-13). Terms: Workstream, Door, Agent, Terminal, Bubble, Run, Checkpoint, Work order, Kind, Rail, Brief (`GLOSSARY.md`). Acceptance only; work ownership and dependencies live in GitHub Issues. No implementation is claimed by this specification.

The owner chose one Door per Workstream, a Door that hands out work only, and children answering the user in their own Terminals. These choices replace the custom Workstream view. Checkpoint storage and `checkpoint_write` stay as M10 in `scenarios/mcp.md`; the Checkpoint rewind picker belongs to #808. The Workstream working row belongs to the removed view, so #1116 has no remaining surface to implement. #1097 keeps its shared Glyph and Rail work; its application to Workstream-view rows goes.

Implementation is three sequential PRs, each within one module directory and about 2000 changed lines (rule 3): Agent launch/Brief (`crates/agents`), MCP offering (`crates/rup`), then desktop removal and terminal selection (`apps/desktop`). Scenario amendments travel with the implementation that replaces their behaviour. Any missing implementation prerequisite is a scoped Issue, never an unobserved assumption or an expansion into another module.
