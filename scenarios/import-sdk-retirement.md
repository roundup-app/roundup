# SDK-owned session lookup

Import and continuation use the configured Claude Agent SDK as the storage authority inside the Claude Code Adapter. This acceptance completes the retirement already ordered by **Agent-led import using vendor session tools** in `scenarios/import-work.md`; it changes no Import UI or commit authority.

**U4251a retire the parallel discovery implementation.** Given the SDK-backed listing and snapshot conversion, when this retirement is implemented, then roundup contains no definition or caller of `encoded`, `is_possible_bucket`, `scan_records` or `in_linked_worktree`, no custom enumeration of vendor bucket directories (including `index_sources`), and no replacement encoder, guessed hash or relocated copy of those algorithms. Mark this then-clause policy: review the implementation diff and search production and test sources under `crates/agents/`; do not add a source-text test. Remove the legacy `discover_recent` scanner or route its remaining callers through the existing SDK listing. Keep selected-source complete-record validation and revision-bound conversion; they are not a second discovery parser.

Given the retired scanner's cwd decisions, when migrating its callers and tests, then neither multiple recorded cwds, a missing historical folder nor a Project-owned linked Worktree is by itself an import exclusion. Mark this then-clause policy: remove the old cwd-ambiguity, missing-folder and blanket linked-Worktree rejection branches, and retire their contradictory assertions. Keep another Project, sibling-prefix collisions, subagents, foreign source identity and internal `.roundup/` sessions ineligible under U3523a. Do not remove contract enum variants merely because an old scanner used them; any contract change follows the Contract recipe and changes every caller.

**U4251b SDK membership reaches snapshot validation.** Given isolated effective vendor storage with recent saved top-level sessions recorded at root then root/sub, at a deleted external Project Worktree then root, and in an existing registered linked Project Worktree, when the real Daemon lists and the user confirms those sessions, then each is offered once and published once using the same SDK-derived membership and mapped cwd at listing and commit. Neither a historical bucket name nor the retired cwd exclusions may reverse that decision. Assert `u4251b_sdk_membership_survives_snapshot_validation` through the real Daemon/public import seams with real SDK reads, real Git Worktree provenance, a fixed clock and fake Claude. Extend or rename an existing journey rather than duplicating its proof. For each input assert source identity, mapped cwd, retained complete records and unchanged original bytes; finished imports create no Attempt or Terminal.

Given a listed source, when its selected-source snapshot is read, then source identity and revision still bind the retained records; a changed, replaced, vanished or foreign-identity source refuses without publishing that source. Assert the surviving stale-source clauses in `u3082c_appended_source_is_refused`, `u3082c_replaced_source_is_refused`, `u3082c_source_changed_during_validation_is_refused` and `u3126b_first_import_requires_its_original`; extend the migrated selected-source test with `u4251b_foreign_identity_is_refused` for foreign identity. Policy: preserve duplicate-identity refusal and the existing complete-record/partial-tail, size, deadline, per-source atomicity, cleanup and retained-replay guarantees. SDK enumeration and single-session reads replace bucket walks; bounded membership projection is permitted only for the compatibility gaps documented under U3523a, bound to that same source revision. Unknown or failed SDK lookup is an explicit error with recovery, never a successful empty list or permission to fall back to the retired scanner.

**U4251c continuation resolves the saved identity through the SDK.** Given an existing saved conversation whose SDK-resolvable location differs from the path the old cwd encoder would construct, including a truncated hashed long-path bucket and a conversation whose recorded cwd changed, when roundup records or reads that conversation and resumes its imported Agent, then it resolves the exact saved identity through the SDK and resumes with the expected sessionId and mapped cwd through normal launch acknowledgement. No encoded-directory guess may select or create a substitute conversation. Assert `u4251c_sdk_lookup_continues_the_selected_conversation` through the existing Launcher/Daemon seams with isolated real SDK storage and fake Claude, checking retained content, source immutability, launch argv, acknowledgement and acceptance of the user's next prompt. Cover both inputs as one table of the same claim; reuse U3523b's journey helpers and preserve its live-session identity rule.

Given a retained conversation and a Mark, when roundup copies or restores it for continuation, then the returned saved identity is SDK-readable, contains the complete selected records and leaves the original unchanged; reopening and replay preserve the published identities without another automatic launch. Assert `u4251c_retained_copy_is_sdk_readable` at the existing conversation-copy seam with real SDK reads and isolated storage, and retain the existing public replay tests in check 3. Policy: lookup covers `conversation_path` callers, including overview, record and retained-copy preparation, without assuming SDK metadata exposes a transcript path or replacing full-record retention with filtered `getSessionMessages` output. Establish any missing SDK storage capability from the pinned SDK before implementing the smallest Adapter-local conversion; do not recreate bucket discovery. A missing runtime or unresolved identity reports its cause, preserves recoverable retained work and never falls back to a guessed path.
