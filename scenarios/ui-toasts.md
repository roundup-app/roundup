# UI: Toasts tell the user what needs them (U410 to U414)

Module: `apps/desktop` (the webview). Ids: U410 to U414.

Found by the user's report #1111: roundup has no notification at all; the Dock badge (`rail/DockBadge.tsx`) only counts. The user asked for a clean toast and a short sound that hides by itself, with no bell icon, no badge in the window bar and no list of past toasts. GLOSSARY.md's _Signal_ lists "notification" as _Avoid_, so the implementing PR adds **Toast** to `GLOSSARY.md` (Contract recipe): "A small card with an Agent's Glyph, its name and one line, shown for a moment when that Agent needs the user, fails or changes the user's work; it hides by itself and is never kept in a list." Which Actor wrote a Todo or Pad is read from what the webview already receives: `todo.updated`, `pad.changed` and the Touch log (P2). If an event lacks the writer, the Builder adds it by the Contract recipe with every caller in the same PR. Playing the sound while roundup is not in front needs the App only if the webview cannot do it; then it is one App seam command named in `GLOSSARY.md`, with a fake in `src/testing/fakeApp.ts`. Observer: Vitest `u410_` to `u414_` against the fake App, a fake clock and the U26 harness at 1280 by 820 and 1280 by 800, dark, with `window.__checks()` in `artifacts/ux/U410/`. The sound's audibility and WKWebView's focus events stay the user's `just app` observation. Moves: D1, D2, D5, D6, D9.

**U410 which events make a Toast.** Given an open Project, when an Agent's Kind becomes `needs-you`, or becomes `error`, or an Agent other than the user changes a Todo whose `creator` is the user or a Pad the user owns, then one Toast shows and one sound plays. No Toast and no sound for: an Agent's Kind becoming `done`, `idle`, `working` or `blocked`; a Todo made by an Agent; a Pad an Agent owns; the user's own change; an Agent's Kind already `needs-you` on load; or a repeat of the same Kind. Tests: `u410_needs_you_makes_a_toast`, `u410_error_makes_a_toast`, `u410_an_agent_editing_the_users_todo_or_pad_makes_a_toast`, `u410_other_changes_make_none`, `u410_loading_a_project_makes_none`.

**U411 what a Toast shows and how it leaves.** Given a Toast, then it holds the Agent's `KindGlyph` (decorative), its name as the Rail shows it and one line of what happened (`Needs you`, `Failed`, `Changed Todo "<title>"`, `Changed Pad <name>`), cut with an ellipsis at one line; it is a `button` with an accessible name of the same words and sits in a polite live region. It hides by itself after 5 s on the fake clock; while the pointer is over it or focus is in it the timer stops, and leaving restarts the full 5 s. `Esc` with focus in it hides it. No bell, no counter in the window bar, no list and no history anywhere: after a Toast hides nothing of it is in the DOM. Tests: `u411_a_toast_shows_glyph_name_and_one_line`, `u411_it_hides_after_five_seconds`, `u411_hover_and_focus_keep_it`, `u411_nothing_of_it_stays`, `u411_no_bell_or_list_exists`.

**U412 clicking a Toast opens what it names.** Given a Toast for an Agent, when it is clicked, then that Agent's Rail row is selected as a click on the row does and the Toast hides; for a Todo or Pad, its Drawer opens as the Shelf's row does (U15) and the Toast hides. A Toast naming a removed Agent, Todo or Pad hides and shows U80's one failure line. Tests: `u412_clicking_selects_the_agent`, `u412_clicking_opens_the_todo_or_pad_drawer`, `u412_a_gone_target_shows_the_failure_line`.

**U413 when roundup is not in front, and for the selected Agent.** Given roundup is not the app in front (`document.hasFocus()` false or `visibilityState` hidden), when an event of U410 happens, then the sound plays at once and no Toast shows; when the user comes back, the Toasts that were held show, merged as U414 says, and no sound plays again. A Toast hidden by its timer while the window was away is not held. While roundup is in front, an event for the selected Agent makes no Toast and no sound; an event for another Agent does. Tests: `u413_away_plays_the_sound_and_holds_the_toast`, `u413_coming_back_shows_without_a_second_sound`, `u413_the_selected_agent_in_front_makes_none`.

**U414 few Toasts, never in the way, quiet when idle.** Given ten events inside 1 s, then at most 3 Toasts show at once, newest first, and the rest are one Toast `And N more`; one Agent's repeated events replace its Toast and play one sound per second at most. Its enter and exit are a 150 ms opacity and 8 px translate (`docs/motion.md`, `animate` skill), ease-out, and with `prefers-reduced-motion` they are instant. Colours and sizes are Tokens only. With no event, no timer, listener loop or audio object runs (rule 7): the layer renders nothing and a test counts zero pending timers. Tests: `u414_ten_events_make_at_most_three_toasts`, `u414_repeats_replace_and_one_sound_per_second`, `u414_motion_and_reduced_motion`, `u414_idle_runs_nothing`.
