- **Empty.** Only when `rail.tree` has no row, the centre replaces U38's `Select an Agent or a Terminal` with a light `No Workstream yet` and one button, `start a Workstream`. - **Door states.** When the selected row is a Workstream whose Door has no running program, the centre shows one light state line above U9's `Start supervisor` / `Retry supervisor`, in a fixed block that does not resize the pane. The line is one of:
  - `starting Door…` while a `rail.startDoor` call is pending; the button is disabled, so a repeat activation calls nothing (U9);
  - `Supervisor did not start` after a failed start (U9), beside the `✕ <message>` line and `Retry supervisor`;
  - `Supervisor not started` when the Workstream has no Attempt (A20) and no Terminal;
  - `Supervisor stopped` when it has an Attempt and no running program, followed by `, exited <code>` or `, exited by signal` when the ending is known (U7's wording). `stopped` means launched before and not running now, however it ended, so a Workstream whose first launch failed reads `stopped` after a reload.
- **Running.** A Workstream with a running Door shows its Terminal and no state line. The words never mention a Thread or coordination: the Thread is the Door's Terminal (`GLOSSARY.md`, U467).
