# The Delegate Board: hand Todos to Agents (A3308, U3308 to U3311)

Module: `crates/todos`, `crates/agents`, `crates/rupd`, `crates/contracts`, `contracts/generated/` and `apps/desktop`. Ids: A3308, U3308, U3309, U3310, U3311 (T29 is in `todos.md`). Acceptance for #3308. Decided by the user (2026-10-22): Auto lets the Door pick each unassigned Todo's owner and may start a Subagent for it, every hand-off showing as it happens; each Agent shows "free now" or "busy until 14:40" from the estimates of its open Todos. Builds on U3717 to U3720 (Todos grouped by owner, #2896), T16/T17 (`owner`, `todo.assign`), T29 (the estimate), A3195 (Workstream cap) and #3300's motion carve-out for Agent acts. The look is rebuilt from AffectUI's public Delegate Board docs (`https://www.affectui.com/llms-full.txt`); no code is copied (policy). Drag stays on the existing `@dnd-kit/solid` through `ui/sortable.tsx`. `GLOSSARY.md` gains **Auto** and **Busy until** in the implementing PR (Contract recipe of `.agents/builder.md`).

**A3308 Auto lets the Door hand out unassigned Todos.** Given a Workstream with its Door running, when the user calls `workstream.setAuto {id, auto: true}`, then `auto` persists on the Workstream (default `false`, also after a Daemon restart and for a Workstream stored before the field), `rail.list` carries it, and `workstream.updated` is emitted once; setting the value it already has changes nothing and emits nothing; an unknown id is `NOT_FOUND`. While `auto` is true, each open Todo in that Workstream with `owner: null` reaches its Door once as a plain-text Message (B33) naming the Todo id, title and estimate; Todos already unassigned when Auto turns on reach it too, in T10 order. The Door answers with `todo.assign {id, owner}` for an Agent of that Workstream (recorded in the Todo's history as T17 says), or starts a Subagent (A7) that it then assigns the Todo to; the Subagent start obeys the Workstream cap (A3195) like every start. A Todo owned by `Actor::user()` never moves under Auto, nor does one already owned by an Agent. With `auto` false nothing is sent, and turning it off stops further Messages (hand-offs already made stay). A Todo is sent once per time it becomes unassigned: a restart replays nothing already sent. Each hand-off emits `todo.updated` like any assign, so the Board shows it as it happens (U3311). Tests: `a3308_set_auto_persists_and_emits_once`, `a3308_auto_on_sends_each_unassigned_todo_to_the_door_once`, `a3308_me_and_agent_owned_todos_never_move`, `a3308_auto_off_sends_nothing`, `a3308_a_restart_resends_nothing`, `a3308_the_door_assign_is_recorded_in_history`, `a3308_a_subagent_start_obeys_the_cap`.

**U3308 the Todos by owner read as a Delegate Board.** Narrows U3717. Given the Todos tab (U373) in any scope, then each owner group header shows the owner's name and a free-time line: for an Agent, `free now` when the sum of the estimates (T29) of its open Todos is 0 or no open Todo carries one, else `busy until <HH:MM>` (local 24-hour clock) computed as now plus that sum; when some but not all open Todos lack an estimate the line adds `+ n without estimate`, and when none has one it reads `no estimates`. Done Todos add nothing. Me and Unassigned show a count and no free-time line. The line is recomputed on every `todo.updated` and each minute, from one clock helper (rule 9, policy). Each Agent group lists its open Todos, with a row's estimate (`45 min`) beside its title when set. Tests (`u3308_`, fake clock): `u3308_a_free_agent_reads_free_now`, `u3308_busy_until_is_now_plus_the_sum_of_estimates`, `u3308_missing_estimates_add_nothing_and_say_so`, `u3308_done_todos_add_nothing`, `u3308_the_line_follows_an_estimate_change_and_the_minute`.

**U3309 hand a Todo to an Agent by number key, or by Enter and arrows.** Narrows U152 and U3720. Given the Todos tab with a Todo row button focused, then each Agent header shows a digit 1 to 9 by its name in Rail order (a tenth Agent shows none); a plain key `1` to `9` (no `⌘`, `⌃`, `⌥`, no `⇧`; registered in the registry's Shelf scope, listed in Help and the key hints, never a local `keydown` listener, policy) calls `todo.assign {id, owner}` once with that Agent's Actor and nothing else; a digit with no Agent does nothing; the Todo's own owner does nothing and calls nothing. `Enter` on the focused row lifts it; `↑`/`↓` move the lift between owner groups (Me, Agents in Rail order, Unassigned) and announce the target in a live region (`Move #<id> to <group label>`); `Enter` drops it with one `todo.assign` and `Esc` puts it down with no call. Focus returns to the row button after the refetch (U138), never `body`. The keys do nothing in a text field, on a done Todo's row or with a modifier held. A refused assign shows `✕ <message>` as U3720 says and the Todo stays in its group. `o` and the Assign word of U3720 keep working. Tests (`u3309_`): `u3309_a_digit_assigns_to_that_agent_once`, `u3309_a_digit_without_an_agent_or_for_the_own_owner_calls_nothing`, `u3309_enter_arrows_enter_assigns_once_and_esc_cancels`, `u3309_focus_returns_to_the_row`, `u3309_the_keys_are_inert_in_fields_with_modifiers_and_on_done_rows`, `u3309_the_digits_are_registered_shelf_bindings_listed_in_help`.

**U3310 the Auto switch.** Narrows A3308. Given the Todos tab in a Workstream's scope, then a labelled switch `Auto` (role `switch`, Ark UI through `ui/`, `aria-checked` the Workstream's `auto`) sits in the tab's head with the text `Door hands out unassigned Todos`; pressing it (Space or click) calls `workstream.setAuto` once with the new value and shows the new state after `workstream.updated`, not before. In the Overview or a scope with no Workstream the switch is absent. A refused call keeps the old state and shows `✕ <message>`. While Auto is on, an Unassigned group reads as handled by the Door (`the Door is handing these out`). Tests (`u3310_`): `u3310_the_switch_calls_set_auto_once_and_follows_the_event`, `u3310_the_switch_is_absent_without_a_workstream`, `u3310_a_refused_call_keeps_the_state_and_shows_its_cause`, `u3310_the_switch_is_a_labelled_keyboard_reachable_switch`.

**U3311 a hand-off moves with motion; the Agent under a drag shows its new busy time.** Narrows U3718, #3300's carve-out for Agent acts and U3308. Given a Todo dragged over an Agent's group (the drag of U3718, `@dnd-kit/solid`), then the Todo lifts and follows the pointer and the Agent's line previews `busy until <HH:MM>` with the dragged Todo's estimate added, reverting if the drag is cancelled; the preview is display only and calls nothing. On a drop, a key (U3309) or a Door hand-off (A3308), the row glides once into its new owner's group when `todo.updated` and the refetch place it (a transform and opacity transition within the Tokens' motion durations, no layout property animated); a burst retargets the running glide and nothing queues. Under `prefers-reduced-motion` the row appears in its group at once. A Door hand-off shows as it happens without stealing focus or scroll, and no more than one glide runs per row. Tests (`u3311_`): `u3311_the_agent_under_a_drag_previews_its_busy_time_and_reverts_on_cancel`, `u3311_a_hand_off_glides_once_and_a_burst_retargets`, `u3311_reduced_motion_moves_at_once`, `u3311_a_door_hand_off_keeps_focus_and_scroll`. Rendered (policy, design critic only): at 1512×950 in dark only (U3725), capture the Board with a drag over an Agent, Auto on, and a hand-off under `artifacts/ux/delegate-board/`; only Tokens; `window.__checks()` keeps every Check passing on main; Moves D2, D5 and D6.
