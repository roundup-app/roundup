# Remove Time and Timeline

Module: `apps/desktop`, then `crates/contracts`, `crates/agents`, `crates/rupd`, `crates/rup`, `contracts/generated/` and `GLOSSARY.md`. Source: #4454, the owner's 2026-10-27 choice on a screenshot of the centre bar showing "Time", "Timeline" and "Back to Ask": "also this bar should be full removed, the ask is always accessible no link needed, and time and timeline proved to be useless I want to fully remove them". Ids: U4454a–U4454d. Journey: Understand and Intervene (`.agents/data/journey.md`). This specification orders implementation; it claims no delivered behavior.

Policy: this file supersedes every clause that names the Time view, the Timeline view or the centre bar's Back to Ask. The implementation removes their code, copy, styles, scenario text and tests together, and keeps each unrelated clause. Ask stays reachable through the Rail's Project root button (`apps/desktop/src/rail/Rail.tsx`, `rail.select(null)`); no replacement link, tab row or navigation state is added. Retained: Agent Terminals, Escape on requested screens, direct Agent access, and every unsubmitted-draft guarantee (P11).

Order of work, one PR per module directory (rule 3), each blocked by the one before it: (1) `apps/desktop` (U4454a, U4454b); (2) the read side, `project.measurementSummary` with its contract types and generated bindings (U4454c); (3) the write side, collection and storage that only the retired read used (U4454d). Each PR names what it kept because another feature still reads it.
