**U2539a `agent.changedFiles` lists what the Agent changed against its Base.** Adds one Daemon method; changes no Token. Given an Agent with a Worktree (G2), then `agent.changedFiles {id}` returns `{files: [{path, status, line}]}`, sorted by `path`:
- **Which files.** A file is listed when the Worktree's working tree differs from the merge base of the Agent's branch and its Base (`Worktree.base`, G3's Base): committed, staged, unstaged or untracked, outside `.roundup/`. A committed change later reverted is not listed. Asserted in `u2539a_lists_committed_staged_unstaged_and_untracked_files` and `u2539a_a_reverted_change_is_not_listed`.
- **Status.** `status` is one of `added`, `modified`, `renamed`, `deleted`, `untracked`; a renamed file lists its new `path` and `from`, its old one. Asserted in `u2539a_reports_each_status`.
- **Line.** `line` is the 1-based first line that differs in the working copy, `null` for a deleted or binary file. Asserted in `u2539a_line_is_the_first_changed_line`.
- **Read-only.** The branch, the Base and the files are the same after the call (G3's rule). Asserted in `u2539a_changes_nothing`.
- **Failures.** An Agent with `worktree: null` fails `no_worktree`; a Worktree directory gone from disk fails `worktree_missing`, as G3 does. Asserted in `u2539a_no_worktree_and_missing_worktree_fail_as_g3_does`.
