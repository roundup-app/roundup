# UI: primary navigation stays available

Acceptance for the implementation work order #4274. Journey stages: Enter, Understand and Intervene. Project tabs, the Rail and the Terminal bar are primary navigation. They remain mounted at rest; the calm-screen rule applies to secondary facts and inspection. This specification amends U2539b and restores U469's bar clauses. Shelf, Drawer, resource inspection, history and other secondary surfaces retain their on-demand behavior.

Policy: implement through the existing connected App and its current header, Rail, Bubble, menu and shortcut seams. Restore the Project strip's placement from `2efe45864`, retaining subsequent flat-tab styling, rename, overflow, attention, native title, window drag and zoom behavior. No new RPC method, App seam command, Token or glossary term is ordered. The test names below are required implementation observers, not claims that tests or behavior already exist. The specification PR leaves #4274 open.

**U4274a Project tabs share the native window bar.** Given an open Project, including an empty Project, with nothing selected and no requested surface, when the connected App settles, then its Project tablist is inside `WindowBar`, beside the traffic-light reservation, with no second Project-tab strip in the Rail or centre.
