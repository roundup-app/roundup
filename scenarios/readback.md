Module: `crates/agents` (the input, the result check, the run's state), `crates/contracts`, `crates/rupd` (route and policy). Ids: RB1, RB2, RB3, RB4, RB5, RB6, RB7, RB8, RB9. Decisions this specification takes:
- **Hunk id:** `<path>#<n>`, `n` counting from 1 the hunks of that path in diff order; the hunks are those `agent.compareFile` shows for `agent.changedFiles` against the same `to` (U7672a), so the model and the view name the same hunk.
- **Input cap:** 256 KiB of hunk text and 400 hunks, whichever is first; over it the run fails with `tooLarge` and says the cap.
- **Results kept:** the Daemon holds the last result per `(Agent, to)` in memory until the Agent is removed or the Daemon restarts; a new start replaces it. Closing the view cancels nothing.
- **Two steps, one Role:** step one writes the account from the diff, flows and nothing else; step two compares that account with the Agent's last message. Both calls use A7686's `readback` pair.
- **Stale:** the diff changed since the run started, read as the set of `(path, blob id)` of `agent.changedFiles` for the `to` (U7673a's blob id, the change signal #7675 and #7680 use).

**RB1 the run's input holds the hunks, the call paths done and, of the conversation, only the Agent's last message.** Given an Agent with a Worktree of its own and a diff of three files, then step one's stdin holds each hunk with its path and hunk id (`a.rs#1`), and the flows `agent.callPaths` had done when the run started as `{id, entry, hunks}` (entry function, hunk ids in call order); step two's stdin holds step one's account and the last message. A marker only the conversation holds is in neither. Asserted in `rb1_the_input_is_the_hunks_the_flows_and_the_last_message_only` (Rust, fake `claude` that records stdin).
- **Flows done only.** The run neither waits for a trace nor starts one; with none done (no server, failed, still tracing, or Rust not asked for) the input holds no flows. Asserted in `rb1_a_run_neither_waits_for_nor_starts_a_trace`.

**RB2 nothing but the user's call starts a readback.** `agent.readbackStart {id, to}` starts a run and answers `{state: "reading"}` at once; the view's `agent.readback {id, to}` only reads state. Given a write to the Worktree, an Agent event, a Stop, `agent.changedFiles`, `agent.compareFile`, `agent.callPaths` and the passing of a timer's worth of time, then the fake `claude` is launched zero times. Asserted in `rb2_only_the_start_method_launches_the_call`. A start while one is reading for the same `(Agent, to)` answers `reading` and launches nothing more. Asserted in `rb2_a_second_start_joins_the_run_in_flight`. A shared checkout (no Worktree of its own) fails with `no_worktree`, as U7672a. Asserted in `rb2_a_shared_checkout_has_no_readback`.

**RB3 the result has a fixed shape.** Given a read run, `agent.readback` answers `{state: "read", overview, diagram, flows, modules, unplaced, gaps}`: `overview` two or three sentences; `diagram` the parts and calls as text, one call per line as `A -> B` (a chain `A -> B -> C` allowed), with a line `Before` or `After` starting each panel where the shape changed, the format `parseDiagram` (`apps/desktop/src/changes/diagram.ts`) reads (policy: the prompt asks for it, the Daemon never fails a run on it; a diagram with no `A -> B` line still answers and the App shows its words); `flows` each `{id, name, source: "code"|"readback", steps}` with `steps` in call order, each holding hunk ids; `modules` one short account per module; `unplaced` the hunk ids no flow holds, computed by the Daemon, never by the model; `gaps` as RB4. An answer that is not this shape fails with `badAnswer`. Asserted in `rb3_a_read_run_answers_the_fixed_shape_and_computes_unplaced` and `rb3_a_malformed_answer_fails_with_its_cause`.
- **Hunk ids are real.** An id in the answer that names no hunk of the input fails the run with `badAnswer` naming the id. Asserted in `rb3_an_unknown_hunk_id_fails_the_run`.
- **Code flows stand.** A result names a code flow by its id and may add flows (`source: "readback"`); one that drops a hunk from a code flow, moves one to another, or reorders one is refused with `badAnswer` and a cause naming the flow. With no code flows every flow is the readback's own. Asserted in `rb3_a_result_that_moves_or_reorders_a_code_flow_is_refused` and `rb3_with_no_code_flows_every_flow_is_its_own`.

**RB4 a gap is one line at the diff's own line.** Given a last message and a diff that disagrees with it, then each gap is `{path, quote, line}`, rendered as "<Agent> said: … The diff: …", with `path` a changed file, `quote` a fragment of a line the diff holds (checked by the Daemon as a substring of that file's hunk text) and `line` the new-side line it points at. A gap whose path or quote the diff does not hold is dropped, never shown. With no last message, or an empty one, step two is not run and `gaps` is empty. Asserted in `rb4_a_gap_carries_the_agents_words_and_a_quote_the_diff_holds`, `rb4_a_gap_the_diff_does_not_hold_is_dropped` and `rb4_without_a_last_message_there_are_no_gaps`.
- **Step two fails alone.** A failure of step two leaves the account read, with `gaps: {failed: cause}`. Asserted in `rb4_a_failed_comparison_keeps_the_account`.

**RB5 the states run in order and a failure says why.** Given one run, `agent.readback` answers `notRead` before any start, `reading` from the start (every other method, `agent.changedFiles` included, still answers meanwhile), then `read`; a failed call answers `{state: "failed", cause}` in words, with the Role's call error as the cause and no token, price or usage figure; a start after `failed` runs again (Retry). Asserted in `rb5_states_run_not_read_reading_read_and_failed_retries`, and in `rb5_a_failure_cause_carries_no_usage_figure` (a fake `claude` that prints usage; the cause holds none of it).

**RB6 the last message comes from the vendor record inside the Adapter.** The Stop's last message is read in `crates/agents/src/claude_code/` (where A7180 reads it) and held by the Agent's state as neutral text; the Daemon passes it to step two and nothing outside `claude_code/` reads a vendor record. An Agent that has had no Stop has none. Asserted in `rb6_the_last_message_crosses_the_adapter_as_neutral_text` and `rb6_an_agent_with_no_stop_has_no_last_message`.

**RB7 a result goes stale when the diff changes, and the Daemon keeps it.** Given a read result, then a write that changes a file of the diff makes `agent.readback` answer `{state: "stale", ...the result}` ("Changed since the readback"); a write outside the diff, or one that leaves every blob id as it was, leaves it `read`; a later start replaces the result. Closing the view, and a second `agent.readback` call, leave the run and its result as they were; a restart of the Daemon drops them (`notRead`). A run that was reading when the diff changed ends as `stale` once read. Asserted in `rb7_a_write_to_the_diff_makes_the_result_stale`, `rb7_a_write_outside_the_diff_or_with_same_bytes_leaves_it_read`, `rb7_closing_the_view_does_not_cancel_the_run`.

**RB8 a diff over the cap fails and says the cap.** Given a diff of 400 hunks plus one, or over 256 KiB, then `agent.readbackStart` answers `{state: "failed", cause}` with `tooLarge` and the cap in the words, and the fake `claude` is launched zero times; a diff just under it runs whole, with no hunk cut. Asserted in `rb8_a_diff_over_the_cap_fails_naming_the_cap_and_launches_nothing` and `rb8_a_diff_under_the_cap_is_sent_whole`.

**RB9 a run reads only flows that match the diff it reads.** Given call paths done for an Agent and `to`, then a write that changes a file of the diff, then `agent.readbackStart`, the step-one stdin holds no flows, though the earlier trace is done. Given a newer trace still running (`agent.callPaths` answers `tracing`) after an earlier one was done, a start's step-one stdin holds no flows either, as RB1 says for a trace still tracing. A trace finished for the diff as it now stands is held: a start after it holds its flows. Asserted in `rb9_a_trace_of_an_older_diff_is_not_read` and `rb9_a_trace_in_flight_leaves_no_flows` (Rust, fake `claude` that records stdin).
