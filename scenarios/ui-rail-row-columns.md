# UI: Rail rows hold one line and one age column

Module: `apps/desktop` (the webview). Ids: U7205a–U7205g. Work Issue: #7205. Journey stage: Understand (`.agents/data/journey.md`). Source: the owner, 2026-11-15, on Rail screenshots. Webview only: no RPC method, App command, contract, code term or new Token. Terms: Rail, Status, Kind, Machine, Tooltip (`GLOSSARY.md`).

Amends U6640a and U6640b (`scenarios/ui-tooltip-anchor.md`: status words in the row), U2228c (`scenarios/ui-truncated-names.md`: no Rail row Tooltip), U5231b's age text for Rail rows (`scenarios/ui-rows-state.md`), U5147a's trailing column (`scenarios/ui-rail.md`) and U5765's rendered policy with A5765e's rendering (`scenarios/agent-project-start.md`). Every other clause of those holds.

**U7205a A row shows no status words; the state glyph's tooltip carries them.** Given a Rail row of any Kind (`error`, `needs-you`, `blocked`, `working`, `done`, `idle`) and any row kind (Agent, Door, Workstream, Mode, child), then the row holds no status label text and no `FailureLine`, inline or on an extra line. When the pointer rests on the state glyph or it takes keyboard focus, one shared `ui/Tooltip` opens with the status label, and for `error` the reason and next action of U5151a. The glyph's accessible name holds that same text. Reading it sends no input and retries nothing (U5151a). Tests: `u7205a_a_row_holds_no_status_words` (jsdom, one case per Kind and row kind: no label text, no error line in the row), `u7205a_the_glyph_tooltip_and_name_carry_the_status` (hover and focus open the tooltip with the label, an error's reason included, and the accessible name equals it).

**U7205b One line per row, always.** Given any Rail row with a long name, an error, an attribution and a remote Machine, then the row is one line: no element of it wraps, and no second line holds a reason, attribution or machine. Policy (design critic): all row border-box heights are equal within 1 CSS px at every depth, in every state, on `agents-10` and `tree-40`.

**U7205c Ages share one right-aligned column.** Given Rail rows of every kind at depths 0 to 3 with ages from seconds to days, then each row's age sits in a fixed trailing slot at the row's end edge, in `tabular-nums`, as `<n>s`, `<n>m`, `<n>h` or `<n>d` (`now` is not used; under 1 s reads `0s`), and ticks in place as U5231b orders, whose boundaries and clock still hold. Every age's right edge lands on one x within 1 CSS px, across rows, depths and Workstreams, in rest, hover, focus, selection and tick. The name truncates with `…` before the age moves; hover, selection and a tick move nothing. The drag handle, the worktree and PR chips, the machine icon (U7205d) and the attribution icon (U7205e) take fixed slots left of the age, so the age's x never depends on which of them a row shows. Test: `u7205c_age_text_uses_short_units` (jsdom, table over 0 s, 59 s, 60 s, 59 min, 60 min, 23 h, 24 h, 6 d, 28 d, sharing U4709a's elapsed-unit rule). Policy (design critic, `window.__checks()` and a bounding-box reading on the capture): the right-edge x is equal across all rows in every state.

**U7205d The Machine shows as an icon on remote Agents only.** Given a Rail row of an Agent on this Mac, then it shows no machine mark and the words "This Mac" appear nowhere in the App. Given an Agent on another Machine, then its row shows one lucide `server` icon (through `ink/Icon.tsx`) in a fixed slot left of the age; hover or focus opens a Tooltip with the Machine's name, or "offline" when `reachable` is false, and its accessible name holds the same text. A single-Machine setup shows no mark. Tests: `u7205d_a_local_agent_shows_no_machine_mark` (jsdom; also asserts no "This Mac" text in the Rail and Project tabs), `u7205d_a_remote_agent_shows_the_server_icon_with_the_machine_name_or_offline` (hover and focus).

**U7205e Attribution is an icon, never a line.** Amends A5765e's rendering and U5765's rendered policy: a row started by another Agent or Project shows one small icon in its own fixed slot left of the age, reserving no second line and leaving no gap between rows. Hover or focus opens a Tooltip with the full "started by <Agent> (<Project>)" text, source names only, no raw ids or paths, readable after the source Agent stops; its accessible name holds the same text. Tests: `u7205e_attribution_is_an_icon_with_the_started_by_tooltip` (jsdom: hover and focus, no text in the row), and U5765's attribution test asserts the icon's tooltip. Policy (design critic): rows with and without attribution sit at the same pitch.

**U7205f Nesting moves no edge.** Given `tree-40` with an Agent under an Agent under a Workstream (depth 3, such as Loop control › Image Drop Fix › Drop Probe), then depth indents only the glyph and the name, and the name truncates first. The Rail's width, the Workstream's frame and border and the trailing column hold the same x at depths 0 to 3, and the Rail has no horizontal scroll. Test: `u7205f_depth_moves_no_edge` (real headless Chromium on the `_browser.test` lane with `tree-40`: the Rail's `scrollWidth` equals its `clientWidth`, and the age's right edge, the Workstream frame's right edge and the Rail's right edge equal their depth-0 values within 1 CSS px at depth 3).

**U7205g The class is fixed: one trailing column for every row kind, and no repeated word.** Every Rail row kind (Agent, Door, Workstream, Mode, child) uses the same trailing column of U7205c. The build audits the Project tabs and the row's other text for a word that repeats a glyph or icon, removes each, and lists each audited element and its change in the PR body. Test: `u7205g_every_row_kind_uses_the_trailing_column` (jsdom: each row kind renders the age in the one trailing-slot element).

Not wanted: hiding the age; a machine mark on a single-Machine setup.
