**U3517a the default font ships with the App.** (The face is revised to Fira Code by U4456a.) Given a fresh App with no Terminal font preference and no installed JetBrains Mono, when an Agent pane, a Door pane or a shell Bubble first shows output, then each uses the bundled JetBrains Mono face, including regular, bold, italic and bold italic, without a network request. The existing `ui-monospace, "SF Mono", Menlo, monospace` stack remains the fallback for unavailable glyphs. **U3517b the default grid has Soloterm's pitch.** Given the loaded default face and no saved size override, when the real emulator is shown, then its line pitch is 18–20 CSS px (19 px target; physical screenshot pixels divided by device pixel ratio), and its rendering meets U3517f's Linux rendered observer.
