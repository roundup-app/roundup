**U3517a the default font ships with the App.** (The face is revised to Fira Code by U4456a.) Given a fresh App with no Terminal font preference and no installed JetBrains Mono, when an Agent pane, a Door pane or a shell Bubble first shows output, then each uses the bundled JetBrains Mono face, including regular, bold, italic and bold italic, without a network request. The existing `ui-monospace, "SF Mono", Menlo, monospace` stack remains the fallback for unavailable glyphs. Font readiness precedes the first authoritative fit; an output stream arriving while it loads keeps its bytes and order, and the fitted size sent to the Daemon uses the loaded face. Planned behavioral test: `u3517a_font_readiness_preserves_output_and_fits_once_ready`, through the real emulator and existing App seam, holding font readiness before releasing it. Policy observer: inspect the built App's local font assets, recorded upstream version/hash and bundled OFL notice; in an isolated headless browser with network disabled and no installed face, inspect loaded font resources for each style. Glyph shapes and fallback legibility belong to U3517f's critic, not style assertions in a UI test (rule 10).

**U3517b the default grid has Soloterm's pitch.** Given the loaded default face and no saved size override, when the real emulator is shown, then its line pitch is 18–20 CSS px (19 px target; physical screenshot pixels divided by device pixel ratio), and its rendering meets U3517f's Linux rendered observer. Policy: start calibration from Ghostty's macOS 13 pt default and unadjusted cell metrics; do not assume native points and xterm's CSS `fontSize` are interchangeable or that `fontSize × lineHeight` alone determines rendered pitch. Record the chosen numeric xterm `fontSize`, `lineHeight` and `letterSpacing`, their units, bundled font version, measured cell width/height and pixel ratio in the implementation's evidence. Define all three as Terminal Tokens, with one default-size source for the emulator, settings and zoom reset. Choose values from the rendered measurements rather than changing the window or hiding output to hit the counts. Planned behavioral test: `u3517b_loaded_metrics_drive_terminal_resize`, asserting U13's `terminal.resize` contract after first show and a resize, with the real emulator. Pitch, glyph size, clipping and horizontal spacing are measured by the design critic on U3517f's fixture, never asserted by a UI geometry test (rule 10).
