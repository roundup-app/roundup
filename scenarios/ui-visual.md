Module: `apps/desktop` (the webview). Ids: U130–U137, U161, U476, U3764.

Webview only. No App command, no Daemon method and nothing under `contracts/` changes. `docs/design-system.md` holds the Tokens, the six rules and the checks D1 to D10; each scenario below is the test that proves some of them, and its test name starts with its id. For rendered captures, every Check runs on every visible element in dark and fails when it cannot measure; non-capture behavioral and Token tests retain their supported schemes (U3725). `docs/motion.md` is unchanged.

These scenarios narrow U4 (ink): its Glyph tones for `working`, `idle` and `done`, its hex values and its `--light` and `--lightest` colours are replaced by `docs/design-system.md`. Its contrast ratios stay, as D5. Any `u4_`, `u5_` or `u20_` test that asserts a replaced colour is changed in the PR that replaces it, and the PR names each such test.

**U137 one module measures the checks.** Given the App in the harness (U26), when `window.__checks()` is evaluated, then it returns an object from each id `D1` to `D10` to `{"status": "pass" | "fail", "value": …, "selector": …}` for what is on screen now, in the colour scheme and media the page is in, computed by the same module the `u130_` to `u135_` tests call, so a check has one implementation. A check it cannot measure returns `fail` with the `value` `"not measurable"`, never `pass`. It reads the page and changes nothing the user sees: the state it drives to read a hover, press or focus style is restored. Observers `u137_editor_menu_is_not_an_item_row` and `u137_floating_menu_shadow_keeps_unrelated_shadow_rejection` distinguish editor menu categories and commands from item rows, accept the floating menu surface’s token shadow, and retain rejection of missing Kind glyphs and unrelated shadows, including menu descendants. Test: `u137_`, which also asserts that every id is present, that a stylesheet with a literal colour makes D1 `fail`, and that the object parses under the `checks.json` shape `loop/rules.sh delta` reads (L42).
