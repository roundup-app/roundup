**U454 the Daemon reports the latest real step and the current turn.** Given a Door and a child Agent running through the real Daemon with a fake `claude` that emits the existing Signals and appends realistic session transcript records, when their turns run, then:

- `UserPromptSubmit` begins a turn, clears the previous step and tokens, and records its start once. `PreToolUse`, `PostToolUse` and repeated reads of the same transcript do not restart its clock. A second prompt begins a fresh turn rather than accumulating the previous turn. Test: `u454_a_turn_starts_once_and_the_next_turn_resets_it`.
- The latest `PreToolUse` supplies the tool and target: `Read` with `file_path: /project/src/Thread.tsx` yields `Reading Thread.tsx`; `Bash` with `command: just check` yields `Running just check`; `Edit` or `Write` with `file_path: /project/styles.css` yields `Editing styles.css`. A later tool replaces the earlier step; `PostToolUse` keeps it until another tool begins or the turn ends. Test: `u454_the_latest_tool_and_target_are_the_step`.
- Before a tool starts the step is absent. An unrecognized tool shows its tool name with no invented target; a missing target shows only the action (`Reading`, `Running` or `Editing`). No playful verb, reasoning text or terminal escape sequence is copied into the step. Test: `u454_missing_and_unknown_tools_do_not_invent_a_step`.
- Tokens are the turn's generated output tokens, matching the downward count in the report, not input, cached input, context size or plan Usage. Sum output usage from distinct assistant transcript records belonging to this turn, count a repeated record only once, and add later records incrementally. A missing count is absent, not zero; an observed zero is zero. Partial final records wait for completion; malformed records do not discard the last valid count or stop later valid records being read. Test: `u454_output_tokens_are_incremental_and_not_double_counted`.
- `Stop` freezes the turn's end and duration even though the Adapter returns the Agent to `idle`. A late transcript usage record can finish the count without moving that end. An Interrupt or failure freezes elapsed time but does not claim successful completion. With no observed turn, return no fabricated start, step, end or count. Test: `u454_stop_freezes_the_turn_without_changing_kind`; test: `u454_an_interrupt_failure_or_missing_turn_is_not_a_success`.
- The Door's observations belong to its Workstream row and a child's to that child; switching sessions never attributes one Agent's step or usage to another. Test: `u454_door_and_child_observations_stay_separate`.

Observer: Rust Adapter tests and real-Daemon integration tests named above probe the actual wire response after each Signal and transcript append, including two consecutive turns. Contract serialization alone is insufficient.
