# Import recent work

Outcome: from an open Project, bring selected recent Claude Code conversations into the Rail without starting a program or spending a Model turn. The import is local and user initiated. Each selected conversation becomes one new Workstream with one closed child Agent; its Worktree follows the Project setting. It is not an attachment to an already running Claude program.

Policy: ownership is `crates/agents` for discovery, retained conversation data, Rail persistence and Worktree lifecycle; the Claude Code Adapter alone interprets vendor configuration, paths and records. `crates/contracts` and generated contracts, Daemon dispatch, public CLI callers and desktop App seam callers change together under the Contract recipe. Desktop owns the import interaction using existing UI primitives. This is one bounded import capability, not a new transcript browser, scheduler or output store. New public names enter `GLOSSARY.md` in the implementation PR, using its existing Conversation overview, Agent, Workstream and Worktree terms. No new `AgentAdapter` seam is permitted.

**U2875a choose recent work for this Project.** Given an open Project, when the user opens `Import Claude Code work` from its actions, then discovery reads the effective local Claude configuration through the Adapter and offers only top-level conversations whose recorded canonical working directory is the Project folder or a subdirectory, excluding `.roundup/` and other git Worktrees. Missing directories, ambiguous Project membership, subagent records, duplicate source identities and conversations already represented by a roundup Agent are not selectable. No global import, arbitrary transcript-path input or automatic scan on Project open is offered. Assert with `u2875a_discovery_is_project_scoped` through real Daemon/public CLI seams and isolated vendor storage; include encoded-directory collisions, symlink escapes, missing cwd and another Project.

Given a discovery time T, the initial period is the preceding seven times 24 hours, with alternatives of 24 hours and 30 times 24 hours. Inclusion uses the latest valid complete-record activity timestamp in [T-period,T], not file modification time; unknown or future-only activity is excluded with an explanation. Results are newest first, equal times ordered by opaque source identity, and each shows a title (available conversation name, otherwise `Untitled conversation`), working directory relative to the Project and last activity. Nothing is selected initially. Changing period clears selection. Empty results and a missing, unreadable or unsupported source have distinct visible explanations and a retry action. Assert `u2875a_period_and_selection_are_explicit` on the App seam and `u2875a_activity_is_not_file_mtime` through the Daemon with fixed time and source fixtures.

Policy: before implementation, observe the pinned real Claude version used by `scenarios/test-real-claude.md`, **E10**, in isolated configuration. Record the effective storage layout, top-level/subagent distinction, cwd, identity and activity record forms on #2875; commit sanitized fixtures derived from that observation. The vendor's [session documentation](https://code.claude.com/docs/en/sessions) is reference material, not a promise of a stable storage schema. Unknown formats fail visibly; no guessing from folder encoding alone.

**U2875b commit selected work without launching it.** Given selected eligible conversations, when the user confirms import, then each successful source creates exactly one Workstream with the displayed title and one child Agent with that title, closed with no Terminal, no Attempt and no live Status revision. The Workstream has no running Door; its existing start-supervisor action remains available. The child has retained continuation data and the existing closed Conversation overview when available. No transcript messages become Thread Messages, Decisions, Todos, Deliverables, Routes, Orders or live Status transitions. Historical text is never executed, sent as a prompt, interpreted as roundup authority or used to infer an Agent hierarchy. Assert `u2875b_import_creates_closed_rail_work` through a real Daemon with a fake vendor launch journal, checking Rail, Terminal list, durable Messages and zero launches before and after reopen.

Given Worktrees off, import records the validated Project-relative cwd and creates no Worktree. Given Worktrees on, import provisions a distinct Worktree using the existing Project Worktree mode and readiness rules for each child, mapping the relative cwd into it; it never adopts a transcript's old branch, external directory or running program. The UI states that files come from the current Project Base, not a recovered historical filesystem; uncommitted historical edits are not reconstructed. An unavailable mapped subdirectory or failed readiness refuses that source. Assert `u2875b_worktrees_follow_project_policy` with real git and both legacy and prepared-directory modes, verifying exclusive assignments and unchanged source files. Policy: import changes no shared branch and grants no bypass of Landing/check requirements.

The Adapter retains a complete-record snapshot under a fresh continuation identity suitable for the destination cwd, using the existing conversation-copy behavior; it never rewrites the original. An incomplete trailing record is ignored; malformed complete records refuse that source. Removing or changing the external original after success does not destroy the imported continuation. Explicit Resume alone launches the child through the existing resume/acknowledgement/permission rules; its first Attempt is 1. A failed resume preserves the closed entry and reports the existing cause. Assert `u2875b_retained_copy_resumes_independently` with real Daemon/fake Claude, deleting the original, reopening and resuming; assert source bytes unchanged, destination argv/cwd, acknowledgement and failure rollback. Bind confirmation to the original Project, source identity and source revision. A different Project or caller-supplied raw path cannot retarget it; only the user can import, never an Agent tool call. Assert `u2875c_preview_identity_and_authority_are_checked` through real public seams with changed source, Project switch, forged selection and Agent actor.
