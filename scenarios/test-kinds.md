# Kind claim diagnosis

**U482 a U351 Kind mismatch identifies the launch that caused it.** Supplements U351 in `scenarios/ui-first-journey.md`; changes no product outcome, contract or Kind semantics. Scope: `claim_kind` in `crates/rup/tests/e2e/fake_claude.py`, the U351 observer in `apps/desktop/src/testing/u351_kinds_real_daemon.test.tsx`, and the launch path established by the reproduction. A repair outside that ownership needs a linked prerequisite Issue before expanding scope.

Given the real Daemon fixture and U351's ten configured Kinds, when fake `claude` launches claim entries and an Agent's Kind does not match its expected entry, then:

- **Claims.** Each successful entry claim records its index, Kind, pid, parent pid and complete argv under that fixture's `CLAUDE_CONFIG_DIR` or on captured stderr. Exhaustion records the same launch identity and that no entry remains. Concurrent claimants leave complete, individually attributable records and cannot successfully claim the same entry. A Door launched with `--tools` consumes no entry. Asserted by `u482_claims_identify_each_launch_without_duplicate_entries`, exercising the real fixture executable concurrently, including exhaustion and a Door launch.
- **Failure output.** Failure of the existing per-Agent 60-second Kind wait prints the claim records before fixture cleanup, together with the Workstream, Agent id, expected Kind and last observed Status. An absent or unreadable record is reported without replacing the original assertion failure. Asserted by `u482_kind_wait_failure_reports_claims_and_preserves_the_assertion`, forcing a mismatch and an unavailable log through the same failure-reporting path the U351 observer uses.
- **Cause (policy).** The implementation Issue holds a failing reproduction under load, its exact command, revision, load/concurrency settings, attempt count and claim records correlated with Agent creation or Attempt launch evidence. It names the call path that launched any extra claimant, or evidence establishing a different cause. Claim order alone does not identify the caller; the extra-launch hypothesis remains unconfirmed until that correlation exists. Failure to reproduce leaves the Issue open with progress recorded there.
- **Repair.** Once the cause is established, a deterministic regression reproduces that cause before the repair and passes afterwards; its name starts `u482_` and describes the demonstrated cause. It asserts launch/claim/Agent behavior, never merely the contents of the diagnosis report. The implementation Issue names this test and the failing and passing revisions. If diagnosis establishes a different cause, the regression exercises that cause rather than an assumed duplicate click.
- **Kept.** U351's existing assertions, ten expected Kinds and 60-second per-Agent wait remain. The existing `u351_ten_agents_read_their_kinds_the_jump_visits_error_then_needs_you_and_working_is_quiet` passes after repair, including its glyph, jump and quiet assertions. Runs without `FAKE_CLAUDE_KINDS` retain their existing behavior, observed by the existing fake-Claude tests reached by `just check origin/main`.

Checks on main: (1) `claim_kind` in `crates/rup/tests/e2e/fake_claude.py` uses exclusive file creation to assign each configured entry once; (2) `u351_ten_agents_read_their_kinds_the_jump_visits_error_then_needs_you_and_working_is_quiet` in `apps/desktop/src/testing/u351_kinds_real_daemon.test.tsx` waits 60,000 ms for each Agent's expected Kind; (3) `startRealDaemon` in `apps/desktop/src/testing/realDaemonFixture.ts` gives each fixture an isolated `CLAUDE_CONFIG_DIR` and deletes it on stop. These are regression boundaries, not evidence of a diagnosed cause.

Observer: the executable fixture tests and U351's real-Daemon jsdom test, using isolated fixture directories. This diagnostic change makes no native Mac or visual design claim. Investigation commands and their results belong on the implementation Issue; any reproduction script reports one row per failed attempt with its exit code and exits nonzero if any attempt fails (policy).
