# Terminal selection paint

Work Issue: #7640. Journey stage: Intervene — select Terminal output and read what is selected. Module: `apps/desktop` (Terminal rendering). Terms: Terminal, Agent (`GLOSSARY.md`). U7640 changes no contract, RPC method, App seam command, Token or domain term; it keeps U3517c's pinned Terminal selection Tokens and U2680a's emulator-owned selection.

Owner's report: dragging across an Agent's Terminal output paints the selection as a blue field with black blocks over the text, so the selected words cannot be read and the highlight edges are ragged.

**U7640a selected Terminal text stays readable.** Given an Agent's Terminal showing several lines of output, among them lines with a cell background (a prompt line, a diff line, an inverse-video status line) and wide lines of plain text, when the user drags across them with the primary mouse button, then every selected cell shows its character in the selection foreground on one selection background; no cell keeps its own background over the selection, and no selected character is hidden. The highlight of a line ends at the line's last selected cell. When the user clicks once, then no cell stays highlighted. Test: `terminal/u7640_browser.test.ts::u7640a_selected_cells_show_text_on_one_selection_background` drives a real drag in a mounted Terminal and asserts, per selected cell, the painted background equals the selection colour and the glyph colour equals the selection foreground, and that after a click no cell paints the selection colour. Which of the same-screen cells keep their own backgrounds before the drag is the seed's, never the assertion's.

**U7640b the same paint holds in each Terminal placement and renderer.** Given U7640a's output in an Agent's centre-pane Terminal, a Door's Terminal and a Bubble Terminal, with the active and the inactive (focus elsewhere) selection, when the user drags across it, then each placement and each renderer the App can choose (WebGL and DOM) paints the U7640a result. Test: the same file's `u7640b_each_placement_and_renderer_paints_the_same`, parameterised over the placements and renderers; it adds no second drag proof beyond U7640a's.

**U7640c selection does not change the program's view.** Given U7640a's Terminal, when the user drags, copies and clicks away, then the Terminal's rows, scrollback and the bytes sent to the program equal those of the same session with no drag (policy: U3529b owns the byte journal; this clause adds no second test).
