## Surface ownership and copy guard

The following U471 observers are planned implementation tests, not claims that they exist on main. They extend the catalogue seam in `apps/desktop/src/copy.test.ts`; the lint’s fixture tests exercise the same checker called by `just lint-web`, without starting a browser or importing production UI.

- **Ownership (C2).** `u471_copy_modules_belong_to_their_surfaces` asserts that the root `apps/desktop/src/copy.ts` is absent, each production copy caller imports its own surface’s copy module, and no surface imports another surface’s catalogue. A surface is the first directory below `src` containing the caller; nested directories share that owner. Root composition callers belong to `app`. Shared copy has one module under `src`, contains values consumed by multiple surfaces, and has no UI dependencies. Surface modules reference only the shared entries their callers need; no whole-catalogue spreads or root barrel recreate the old entry point. Every copy module is at most 1000 physical lines, including comments and blank lines. The observer checks import resolution and usage, not filenames alone. Policy: extraction and all callers land atomically, with no compatibility shim; subsequent wording repairs may be separate PRs.
- **Callers and duplicates (W1).** `u471_copy_guard_rejects_unused_and_duplicate_values` supplies an unused key and two equal values in different modules, separately, and asserts a diagnostic for each. A caller is a reachable production read through a resolved import: dot access, literal bracket access, aliases and destructuring count; tests and references inside unreachable catalogue entries do not. Nested object/map leaves and formatter branches count. Unresolved dynamic access must produce a diagnostic rather than silently marking every key used. Shared references with a production consumer count transitively. Equal authored values or formatter templates are defined once; values used by multiple surfaces live in shared copy. Templates compare their authored text and ordered parameter slots, independent of parameter names. Passing fixtures cover bracket reads, aliases, destructuring and shared references; duplicating one shared definition fails.
- **Length and fragments (W2).** `u471_copy_guard_rejects_long_labels_sentences_and_fragments` independently rejects `Open this selected Agent` as a label, `This sentence has thirteen separate words and must fail the copy length check.`, and explanatory prose `Storage unavailable.`; it accepts the label `Storage`, prose `Storage is unavailable.`, and imperative `Try again.`. Labels name controls, fields, headings or compact statuses; noun labels are allowed. Explanatory, instructional and error prose is sentence copy and cannot evade checking by being marked a label. Count English word-like segments with `Intl.Segmenter("en", {granularity: "word"})`; each runtime slot counts as one word and its supplied contents are exempt. Labels have at most three words; each sentence has at most twelve. Check every authored branch, helper result, nested value and composed formatter result. Each prose sentence must contain a verb tagged VB, VBD, VBP or VBZ by a pinned deterministic English grammar library; auxiliaries plus a main verb and imperatives qualify, bare noun/adjective or participle fragments do not. Missing or unanalysable prose is a diagnostic, never a silent pass. Parser choice and reuse evidence belong on the implementation Issue. Errors state cause plus an available fix, possibly in separate sentences; `u471_copy_errors_keep_cause_and_fix` exercises failure formatters with known causes and asserts both cause and actionable recovery survive. Unknown causes stay visibly unknown.
- **Vocabulary (W3).** `u471_copy_guard_rejects_internal_vocabulary` independently supplies every term on `GLOSSARY.md`’s `_Avoid_:` lines and Daemon, MCP, session, revision, retained and acceptance. Each yields a diagnostic in authored copy, regardless of case, including formatter branches and nested/helper values. Match complete words or multiword phrases, not substrings (`task` fails; `multitasking` does not); extract the named terms, excluding explanatory qualifications. Inflected plurals of banned nouns also fail. Code keys, wire discriminants and compared strings are not displayed copy. Supplied names, paths, ids, code, Adapter labels, Agent output and Terminal content remain exempt and unchanged; passing fixtures preserve an authored name containing a banned word. Existing Door/Shelf user-label mappings still apply; A32/U350 retire Handoff and Clear control terms.
- **Migration baseline.** `u471_copy_allowlist_only_shrinks` asserts an initial exact inventory of current violations, then independently rejects a new violation, a changed violating value, an added/expanded exemption and a stale exemption after repair. Entries identify rule, stable copy identity, branch and exact authored-value fingerprint, not just a file or key wildcard. Moving an unchanged entry keeps its identity and exemption without adding one. Compare against the merge base; after baseline introduction, the set is a subset and every remaining row matches a current violation. Removing a violation removes its row in the same change. The initial guard passes on unchanged copy; subsequent steps keep main green and end with zero exemptions, zero unused keys and zero duplicate definitions. This baseline covers existing violations only, never ownership or caller-migration requirements.
- **Recovery name.** `u471_copy_guard_uses_one_recovery_name` rejects an authored recovery noun using draft/drafts, retained work, revision or unfinished rail work, and accepts `Unfinished work`. That phrase names saved unsubmitted work everywhere: shared recovery, Rail, Changes, capture and surface failures. Sentence case may lowercase it inside prose; surface/object names and state distinctions remain separate, unchanged data. Open, Copy, Discard and Try again remain action labels, not alternative names. Do not rename code keys, storage fields, wire values or user-authored text. The fixture covers each recovery formatter branch; U472 and the existing unfinished-input observers preserve exact work, original destination, unknown-submit status and storage-only retry semantics.
