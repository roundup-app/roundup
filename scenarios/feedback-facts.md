# The build id of a Feedback dialog's versions line is true for the running App (FB7, FB10)

Module: `crates/desktop`. Ids: FB7, FB10. Acceptance for [#6639](https://github.com/roundup-app/roundup/issues/6639); the versions line of `scenarios/send-feedback.md` (U7210b) reads the stamp. FB8 and FB9 (the App and Daemon logs of the earlier Feedback report) are overturned by U7210f. Decided by the owner (2026-11-07): every report on #6163 named build `a7a2361b3114` though the App was rebuilt from `0baef3ab2`, its App log ended on 2026-11-04 and its Daemon log was empty.

**FB7 the build id is the commit the App was built from.** Given a new commit and a rebuild of `crates/desktop`, then the stamped `ROUNDUP_COMMIT` equals `git rev-parse --short=12 HEAD`, in a checkout and in a git worktree. The build script reruns when HEAD or the ref HEAD names moves, and on no other git change; outside a git checkout it builds and stamps an empty commit. Tests: `fb7_the_stamp_follows_head_after_a_commit` (`crates/desktop`, a temporary repository and worktree, the build script's stamp function run before and after a commit), `fb7_no_git_checkout_stamps_empty_and_builds`, `fb7_rerun_paths_are_the_resolved_head_and_its_ref` (the paths the script emits as `rerun-if-changed` for a checkout and for a worktree).

**FB10 the stamp follows a commit when the branch ref is packed.** Given a repository whose HEAD branch ref lives only in `packed-refs` (after `git gc` or `git pack-refs --all`), when a new commit creates the loose `refs/heads/<branch>` file and the crate is rebuilt, then the stamped `ROUNDUP_COMMIT` equals `git rev-parse --short=12 HEAD`, in a checkout and in a git worktree. The build script watches the loose ref file when it exists and otherwise its nearest existing directory (Cargo reruns every build on a missing watched path), and `packed-refs` when it exists. Tests: `fb10_the_stamp_follows_a_commit_after_pack_refs` (`crates/desktop`, a temporary repository packed, then committed, the build script's stamp function run before and after), `fb10_rerun_paths_watch_the_refs_directory_for_a_packed_ref` (every emitted path exists; for a packed ref it is `refs/heads`).

**Observer.** Commit, run `just app .`, open Send feedback…: its versions line holds `git rev-parse --short=12 HEAD`; repeat from a git worktree. Linux CI runs the tests above with no display.

Policy, Must not: rebuild the crate on every build; fail to build outside a git checkout.
