Given `attachment.save` (U467 removed the Thread's composer that called it), then:

Definition (relocated): **Attachment file**:
The copy of a pasted image the Daemon keeps under its data folder (`attachment.save`) so a path can name it in a Message; a native-dropped Attachment needs none.

- **Save.** `attachment.save` writes `data` decoded to a new file under the Daemon's data directory, `attachments/<n>-<name>`, where `<n>` is a counter that makes the path unique and `<name>` is `name` with every `/`, `\` and control character replaced by `_`; it returns the file's absolute path. A `data` that is not base64, or whose bytes are over 20 MB, fails with a message and writes no file. The file is not deleted by a send; the Daemon removes the files older than 7 days when it starts.
