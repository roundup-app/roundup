# Open Doodles

Pablo Stanley’s [Open Doodles](https://www.opendoodles.com/), bundled under
[CC0](https://www.opendoodles.com/about). No payment or attribution required.

U5163’s seven supplied silhouettes replace the original line-and-patch scenes.
Each SVG contains one even-odd path filled with `--doodle-ground` in a
1024×768 `scene` symbol. The silhouettes total 107,449 bytes.
External SVG use loads only mounted scenes; Vite’s `?no-inline` keeps their
bytes outside the entry and eager JS closure. No runtime optimizer ships.

| running.svg | Todos: begin the next task |
| reading-side.svg | Pads: read and develop notes |

| clumsy.svg | Draft recovery and note drafts: gather unfinished papers |
