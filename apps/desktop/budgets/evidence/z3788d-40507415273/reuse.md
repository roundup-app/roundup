# Installed capability and reuse

Ark Solid 5.39.3 / Zag Combobox 1.45.0 retains a logical ListCollection independent of mounted options. The installed machine's `scrollToHighlightedItem` and `scrollContentToTop` invoke `scrollToIndexFn` with the logical index and lazy `getElement`; no mounted DOM is required to choose an index. A runtime collection probe with 4,000 logical entries returned last `row-3999`, index 3999, next from row-3998 `row-3999`, previous from row-3999 `row-3998`. The first direct import of the transitive Zag package failed module resolution; the public installed Ark collection import succeeded. #4413 supplies deferred content-row focus completion, and the existing holder retains navigation/selection ownership.

Reuse: [TanStack Solid Virtual](https://tanstack.com/virtual/latest/docs/framework/solid/solid-virtual), selected directly as ordered by #4401. [Registry](https://registry.npmjs.org/@tanstack/solid-virtual): MIT, 3.13.50 released 2026-10-26; core 3.19.8. It supplies measurement, range extraction, key identity, scroll-to-index and Solid cleanup. The integration uses those capabilities without a list/selection machine or adapter.

[Solid alternative](https://github.com/inokawa/virtua) / [registry](https://registry.npmjs.org/virtua): MIT, 0.54.0 released 2026-10-27. Its Solid virtual list supports variable measurement and scroll-to-index; it is a maintained viable candidate, not rejected for an invented missing capability. The work order explicitly selects TanStack. Neither Ark's collection nor native overflow windows DOM mounting; they remain the navigation and scroll owners, while TanStack owns the mounted range. Full registry metadata is retained in libraries.json.gz.
