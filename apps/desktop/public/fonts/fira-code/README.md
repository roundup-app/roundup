# Fira Code 6.2

Unmodified upstream WOFF2, OFL-1.1.

- Release: https://github.com/tonsky/FiraCode/releases/tag/6.2 (2021-12-06).
- Archive: https://github.com/tonsky/FiraCode/releases/download/6.2/Fira_Code_v6.2.zip
- Licence source: https://github.com/tonsky/FiraCode/blob/6.2/LICENSE

Regular (400) and bold (700) are bundled. Upstream supplies no italic faces;
the browser synthesizes italic and bold italic from these same local faces.
No remote or installed font is needed for any of the four styles. The emulator
loads all four style/weight combinations before its first authoritative fit.
The retired JetBrains Mono notice remains in the adjacent `jetbrains-mono/`.
