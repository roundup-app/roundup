# R23 retained recording extraction (#3971)

Offline extraction only: no new Daemon, timing pair, profile, baseline or
performance pass. Inputs are the two complete CPU recordings from
`../r23-host-40170055163/`; `input-hashes.json` pins compressed and decompressed
bytes. Their original source/probe/executable identities, compatibility patch,
commands, versions and overhead remain there. Do not substitute the current
host's executables or kernel symbols for those recorded identities.

Run `python3 extract.py.txt` from this directory after changing `root` and
`scratch` to local absolute paths. It decompresses the inputs and invokes perf
6.17.13, retains each command/stdout/stderr/status, and groups perf's emitted
PID/TID/time records. Gzip outputs are complete, with deterministic compression.
The extraction does not record events or run a workload; it adds no profiling
overhead to the original observations. Original CPU controls measured +8.4%
(historical) and +9.5% (candidate) whole-invocation wall overhead, not write-stage
corrections. Original strace wall summaries overlap threads and remain unsuitable
for stage latency.

to read the boundary extracts without altering recorded thread names. The epoch
is perf's recording-local timestamp, not a wall clock shared between references. The
header's displayed capture date is generated by the extraction tool; it does
not change the original lifetime identity.
